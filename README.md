# Techne

**The studio brand of RegenHub, LCA**

Boulder, Colorado · [techne.institute](https://techne.institute)

---

*Techne* (τέχνη) — the Greek word for craft. Before art and skill and practical wisdom were separated into different domains, *techne* held them together: the whole of making.

We recover that wholeness for a moment when technology mostly means replacement. Techne is about augmentation — tools that extend what people can think, make, and coordinate, with the human remaining central.

---

## What We Do

Techne is a venture studio and learning community building regenerative infrastructure in Boulder. We run AI building cohorts, host collaborative work, and develop the coordination tools the cooperative uses to govern itself.

The deeper project is collective intelligence: shared memory, common language, coordinated action. Intelligence no single mind contains.
