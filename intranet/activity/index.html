Feature · Document Comments

What this is

Authenticated members can annotate legal documents inline — anchored to specific sections, paragraphs, or selected text. Comments appear as count badges next to annotated elements; a side panel shows threads.

Scope

  • /legal/bylaws-v2/
  • /legal/membership-agreement-v2/
  • /legal/bylaws-analysis/
  • /legal/membership-agreement-modifications/

Schema

Table: document_comments on hvbdpgkdcdskhpbdeeim

id uuid document_path anchor_id anchor_type anchor_label anchor_text body author_id → participants author_name parent_id → self thread_root_id → self resolved resolved_by → participants created_at

RLS Policies

  • SELECT — members (via participants.auth_user_id)
  • INSERT — member inserting as themselves
  • UPDATE — author only
  • DELETE — author or steward

How it works

  • comments.js loads on all /legal pages
  • Uses own Supabase auth check (no dependency on intranet nav)
  • Text selection triggers floating "+ Comment" button
  • Section headings are clickable comment anchors
  • Count badges injected beside annotated elements
  • Panel slides in; threads visible to all authenticated members
  • Stewards can resolve/unresolve threads
